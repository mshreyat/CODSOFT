# Movie Genre Classification using Machine Learning

## Objective

The objective of this project is to build a machine learning model capable of predicting the genre of a movie based on its plot description using Natural Language Processing (NLP) techniques.

This project demonstrates how textual data can be transformed into numerical features and classified using machine learning algorithms.

---

## Dataset

Dataset Used:
IMDb Movie Genre Classification Dataset from Kaggle

The dataset contains:

* Movie Titles
* Genre Labels
* Movie Plot Descriptions

Target Variable:

* Movie Genre

---

## Project Workflow

### 1. Data Preprocessing

* Loaded textual dataset
* Cleaned and processed text data
* Prepared movie descriptions for analysis

### 2. Exploratory Data Analysis (EDA)

* Genre distribution visualization
* Dataset analysis and inspection

### 3. Feature Extraction

Used TF-IDF Vectorization to convert textual movie descriptions into numerical feature vectors.

### 4. Model Building

Implemented multiple classification models:

* Naive Bayes
* Logistic Regression
* Support Vector Machine (SVM)

### 5. Model Evaluation

Evaluated model performance using:

* Accuracy Score
* Classification Report

### 6. Custom Genre Prediction

Predicted genres for custom movie plot descriptions using the trained model.

---

## Results

* Support Vector Machine (SVM) achieved the best performance for movie genre classification.
* TF-IDF vectorization effectively captured important textual patterns from movie descriptions.
