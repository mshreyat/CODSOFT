# CODSOFT Machine Learning Internship Projects

This repository contains the Machine Learning projects completed during the CodSoft Virtual Internship Program.

The projects focus on solving real-world problems using Machine Learning, Data Analysis, and Natural Language Processing techniques.

---

# Projects Included

## 1. Customer Churn Prediction

Built a machine learning model to predict customer churn using customer demographics and banking information.

### Algorithms Used

* Logistic Regression
* Random Forest Classifier
* Gradient Boosting Classifier

### Concepts Covered

* Data Preprocessing
* Feature Engineering
* Classification Algorithms
* Model Evaluation
* Data Visualization

---

## 2. Credit Card Fraud Detection

Developed a fraud detection system to classify credit card transactions as fraudulent or legitimate.

### Algorithms Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

### Concepts Covered

* Fraud Detection
* Imbalanced Datasets
* Classification Models
* Feature Scaling
* Performance Evaluation

---

## 3. Movie Genre Classification

Implemented a Natural Language Processing (NLP) model to classify movie genres based on movie plot descriptions.

### Algorithms Used

* Naive Bayes
* Logistic Regression
* Support Vector Machine (SVM)

### Concepts Covered

* Natural Language Processing
* TF-IDF Vectorization
* Text Classification
* Feature Extraction
* Machine Learning for NLP
